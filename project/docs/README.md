# YogaTutor - 基于视觉感知和多方向触觉引导的实时动作矫正系统

## 项目概述

YogaTutor 是一个智能瑜伽教练系统，结合计算机视觉和触觉反馈技术，实时检测并矫正用户的瑜伽姿势。

### 核心特性

- **实时姿态检测**：基于 MediaPipe 进行人体关键点检测
- **动作对比评估**：将用户姿势与标准瑜伽姿势进行量化对比
- **DTW 动态时间规整**：支持动作序列的时序匹配
- **智能动作识别**：自动识别用户当前练习的瑜伽动作
- **多方向触觉引导**：通过手腕设备的多马达震动引导用户调整姿势
- **1€ 滤波**：平滑关键点数据，减少抖动

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt.txt
```

### 2. 准备标准姿势

将瑜伽姿势图片放入 `standard_images/` 目录

### 3. 提取标准姿势数据

```bash
cd src
python standard_pose_extractor.py
```

### 4. 启动系统

```bash
# 自动识别模式（推荐）
python unified_main.py

# 或手动选择模式
python main.py
```

## 系统模式

### 自动识别模式

系统自动检测用户正在做的瑜伽动作，无需手动选择：
- 持续分析用户关节角度
- 与所有已注册的标准动作对比
- 识别置信度达标后触发评估

### 手动选择模式

用户选择特定瑜伽动作进行练习：
- 适合针对特定姿势的练习
- 显示标准姿势参考图
- 仅对比选定动作

## 触觉反馈

系统通过 ESP32 控制的手腕设备提供多方向触觉引导：

| 马达 | 方向 | 功能 |
|-----|------|------|
| M0 (上) | 抬高手臂 | 提示向上调整 |
| M1 (下) | 放下手臂 | 提示向下调整 |
| M2 (内) | 弯折关节 | 提示向身体方向调整 |
| M3 (外) | 伸展关节 | 提示远离身体调整 |

## 评分系统

- **90-100 分**: 优秀，显示绿色
- **70-89 分**: 良好，显示橙色
- **70 分以下**: 需改进，显示红色

每个关节有独立阈值：
- 肘关节: ±15°
- 膝关节: ±20°
- 肩关节: ±20°
- 髋关节: ±25°

## 键盘控制

| 按键 | 功能 |
