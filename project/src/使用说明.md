# 网页新版使用说明

## 放到哪里
把 `src/web_mvp_server.py` 和整个 `src/webui/` 文件夹复制到本地 `D:\Projects\Yoga Tutor\src\`（覆盖原 web_mvp_server.py）。
原来项目根目录的 `web\` 文件夹不会被动到；需要用旧页面时加 `--web-dir "..\web"`。

## 启动
```
cd "D:\Projects\Yoga Tutor\src"
python web_mvp_server.py --haptic ble --motors 1,3
```
浏览器打开 http://127.0.0.1:4173

- `--haptic ble | serial | none`：腕带连接方式（none = 不接腕带）
- `--motors 1,3`：只用这几个能用的马达（M0、M2 断线时用 1,3；修好后去掉此参数）
- `--pose "Tree Pose"`：启动时默认的体式

## 新功能
- 体式选择：点顶部「当前体式」，从全部标准姿势里挑（带参考图）
- 腕带状态：顶部显示已连接/连接中/未连接，可点「重新连接」；后台自动重连，腕带没连上也不会卡画面
- 腕带示意图：显示哪个马达在震，点圆点可单独测试某个马达；断线马达标灰
- 画面上骨架按对错着色，关节旁显示实时角度，最需要纠正的关节有红圈
- 关节角度条：标准值、容差范围、当前值一目了然（静止计时期间也实时显示）
- 语音提示（可开关）、震动开关、镜像开关、多摄像头切换
- 本次练习统计：练习时长、达标时长、最高/平均分、得分曲线
- 快捷键：空格 开始/停止，R 重新计时
